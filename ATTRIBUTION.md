# Attribution

This repository is a curated extraction of networking-related work from a local EGOS-2000 teaching operating system worktree.

## Included Source Snapshot

The `snapshot/` directory contains a narrow subset of files relevant to the published project:

- `earth/dev_net.c`
- `apps/system/sys_net.c`
- `apps/user/http.c`
- `apps/user/net_raw_test.c`
- `library/syscall/servers.h`
- `library/syscall/servers.c`
- `library/uip/httpd.c`
- `library/uip/httpd.h`

## Notes on Modification

This repository does not claim authorship over the full EGOS-2000 system. It publishes the networking slice as a portfolio artifact with original notices retained. The value of this extraction is the packaging, explanation, and publication of the networking work as a focused project rather than as a copy of the entire teaching OS.
